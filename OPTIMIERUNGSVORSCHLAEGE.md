### 1. Security: Command Blacklist für nl2bash.sh
**Priorität:** Hoch  
**Aufwand:** 10 Minuten  
**Impact:** Sicherheit +15%

**Problem:** AI-generierte Befehle werden direkt via eval ausgeführt

**Lösung:**
```bash
# In scripts/apollo-os-nl2bash.sh vor Zeile 139 einfügen:

# Dangerous command blacklist
DANGEROUS_PATTERNS=(
    "rm -rf /"
    "rm -rf ~"
    "rm -rf \$HOME"
    "dd if=.*of=/dev/sd"
    "mkfs\."
    "fdisk"
    "parted"
    "wipefs"
    ":(){ :|:& };:"  # Fork bomb
    "chmod -R 777 /"
    "chown -R"
    "> /dev/sd"
)

# Check command against blacklist
for pattern in "${DANGEROUS_PATTERNS[@]}"; do
    if [[ "$command" =~ $pattern ]]; then
        echo "❌ BLOCKED: Dangerous command detected!"
        echo "   Pattern: $pattern"
        exit 1
    fi
done
```

**Vorteil:** Verhindert versehentliche Zerstörung durch AI-Fehler

**Aufwand:** 15 Minuten

# In apollo-os-install.sh nach install_packages() hinzufügen:

verify_critical_packages() {
    log "Verifying critical packages..."
    
    local missing=()
    local critical_packages=(
        "sway"
        "waybar"
        "rofi"
        "alacritty"
        "python3"
    )
    
    for pkg in "${critical_packages[@]}"; do
        if ! command -v "$pkg" &>/dev/null; then
            missing+=("$pkg")
        fi
    done
    
    if [ ${#missing[@]} -gt 0 ]; then
        error "Critical packages missing: ${missing[*]}"
        error "Installation cannot continue. Please install manually and retry."
    fi
    
    log "All critical packages verified ✓"
}

# Nach install_packages() aufrufen:

### 3. Daemon: Graceful Degradation
**Priorität:** Mittel  
**Aufwand:** 20 Minuten  
**Impact:** Reliability +15%

**Problem:** Daemon crasht wenn beide AI-Engines fehlen

**Lösung:**
```python
# In apollo-os-daemon.py, generate() Funktion erweitern:

def generate(self, prompt: str, context: str = "") -> Optional[str]:
    """Generate response using Hybrid AI with fallback"""
    
    full_prompt = f"{context}\n\n{prompt}" if context else prompt
    
    # Try Gemini first
    if self.gemini_available:
        try:
            response = self.gemini_model.generate_content(full_prompt)
            logger.info("Response generated by Gemini")
            return response.text
        except Exception as e:
            logger.warning(f"Gemini failed: {e}, falling back to Ollama")
    
    # Fallback to Ollama
    if self.ollama_available:
        try:
            model = self.config.get('OLLAMA_MODEL', 'qwen2.5:0.5b')
            result = subprocess.run(
                ['ollama', 'run', model, full_prompt],
                capture_output=True,
                text=True,
                timeout=30
            )
            if result.returncode == 0:
                logger.info("Response generated by Ollama")
                return result.stdout.strip()
        except Exception as e:
            logger.error(f"Ollama failed: {e}")
    
    # Both failed - return generic fallback (NEU!)
    logger.warning("Both AI engines unavailable, using fallback response")
    fallback_responses = {
        'greeting': "Hello! Welcome back.",
        'random': "All systems operational.",
        'default': "System message received."
    }
    
    # Simple keyword detection
    if 'greeting' in prompt.lower() or 'morning' in prompt.lower():
        return fallback_responses['greeting']
    elif 'humor' in prompt.lower() or 'fun' in prompt.lower():
        return fallback_responses['random']
    else:
        return fallback_responses['default']
```

### 4. Silent Mode (Do Not Disturb)
**Priorität:** Mittel  
**Aufwand:** 30 Minuten  
**Impact:** User Experience +20%

**Neue Datei:** `scripts/apollo-os-dnd-toggle.sh`
```bash
#!/bin/bash
# Apollo OS - Do Not Disturb Toggle

CONFIG_FILE="$HOME/.config/apollo-os/config.env"

# Read current state
current=$(grep "^APOLLO_DND=" "$CONFIG_FILE" 2>/dev/null | cut -d'=' -f2 | tr -d '"')

# Toggle
if [[ "$current" == "true" ]]; then
    # Disable DND
    sed -i 's/^APOLLO_DND=.*/APOLLO_DND="false"/' "$CONFIG_FILE"
    notify-send "Apollo OS" "Do Not Disturb disabled"
    apollo-speak "Notifications enabled" &
else
    # Enable DND
    sed -i 's/^APOLLO_DND=.*/APOLLO_DND="true"/' "$CONFIG_FILE"
    notify-send "Apollo OS" "Do Not Disturb enabled"
fi

# Reload notification handler
systemctl --user restart apollo-os-notification-handler.service
```

### 6. Wallpaper Rotation
**Priorität:** Niedrig  
**Aufwand:** 30 Minuten  
**Impact:** Visual Experience +10%

**Neue Datei:** `scripts/apollo-os-wallpaper-cycle.sh`
```bash
#!/bin/bash
# Apollo OS - Wallpaper Rotation

WALLPAPER_DIR="$HOME/System/Wallpaper"
CURRENT_LINK="$WALLPAPER_DIR/current.jpg"

# Get all wallpapers
wallpapers=($(find "$WALLPAPER_DIR" -type f \( -name "*.jpg" -o -name "*.png" \)))

# Get current wallpaper
current=$(readlink -f "$CURRENT_LINK")

# Find next wallpaper
found=false
for i in "${!wallpapers[@]}"; do
    if [[ "${wallpapers[$i]}" == "$current" ]]; then
        next_index=$(( (i + 1) % ${#wallpapers[@]} ))
        next_wallpaper="${wallpapers[$next_index]}"
        found=true
        break
    fi
done

# Set new wallpaper
if $found; then
    ln -sf "$next_wallpaper" "$CURRENT_LINK"
    
    # Reload wallpaper
    if pgrep swaybg >/dev/null; then
        pkill swaybg
        swaybg -i "$CURRENT_LINK" -m fill &
    fi
    
    notify-send "Apollo OS" "Wallpaper changed"
fi
```

### 7. Battery Profile Auto-Switch
**Priorität:** Mittel  
**Aufwand:** 45 Minuten  
**Impact:** Power Management +25%

**In Daemon hinzufügen:**
```python
class PowerProfileManager:
    """Automatic power profile switching"""
    
    def __init__(self):
        self.profiles = {
            'performance': 'Performance',
            'balanced': 'Balanced',
            'power-saver': 'Power Saver'
        }
        self.current_profile = 'balanced'
    
    def auto_switch(self, battery_percent: int, plugged: bool):
        """Auto-switch profile based on battery"""
        
        if plugged:
            # Plugged in -> Performance
            if self.current_profile != 'performance':
                self.set_profile('performance')
        else:
            # On battery
            if battery_percent <= 20:
                # Low battery -> Power Saver
                if self.current_profile != 'power-saver':
                    self.set_profile('power-saver')
            elif battery_percent <= 50:
                # Medium battery -> Balanced
                if self.current_profile != 'balanced':
                    self.set_profile('balanced')
    
    def set_profile(self, profile: str):
        """Set power profile via powerprofilesctl"""
        try:
            subprocess.run(['powerprofilesctl', 'set', profile], check=True)
            self.current_profile = profile
            logger.info(f"Power profile switched to: {profile}")
            
            # Optional: Voice announcement
            subprocess.run(['apollo-speak', f'Power mode {profile}'], 
                         check=False, timeout=5,
                         stdout=subprocess.DEVNULL, 
                         stderr=subprocess.DEVNULL)
        except Exception as e:
            logger.error(f"Failed to set power profile: {e}")
```

#!/bin/bash
# Apollo OS - Session Statistics

CONFIG_DIR="$HOME/.config/apollo-os"
STATE_FILE="$CONFIG_DIR/daemon-state.json"
LOG_FILE="$CONFIG_DIR/daemon.log"

# Parse session info
uptime_seconds=$(jq -r '.startup_time' "$STATE_FILE" 2>/dev/null)
startup_time=$(date -d "$uptime_seconds" "+%Y-%m-%d %H:%M:%S" 2>/dev/null || echo "Unknown")

# System info
session_uptime=$(uptime -p)
cpu_usage=$(top -bn1 | grep "Cpu(s)" | awk '{print $2}' | cut -d'%' -f1)
ram_usage=$(free | grep Mem | awk '{printf("%.1f", $3/$2 * 100.0)}')
battery=$(cat /sys/class/power_supply/BAT0/capacity 2>/dev/null || echo "N/A")

# AI Stats
gemini_calls=$(grep -c "Response generated by Gemini" "$LOG_FILE" 2>/dev/null || echo 0)
ollama_calls=$(grep -c "Response generated by Ollama" "$LOG_FILE" 2>/dev/null || echo 0)

# Display with rofi
rofi -dmenu -p "Apollo OS Stats" -mesg \
"Session Started: $startup_time
Uptime: $session_uptime
CPU Usage: ${cpu_usage}%
RAM Usage: ${ram_usage}%
Battery: ${battery}%

AI Statistics:
  Gemini Calls: $gemini_calls
  Ollama Calls: $ollama_calls"

### 10. Backup & Restore
**Priorität:** Mittel  
**Aufwand:** 45 Minuten  
**Impact:** Data Safety +30%

**Neue Datei:** `scripts/apollo-os-backup.sh`
```bash
#!/bin/bash
# Apollo OS - Configuration Backup

BACKUP_DIR="$HOME/.config/apollo-os/backups"
TIMESTAMP=$(date +%Y%m%d_%H%M%S)
BACKUP_FILE="$BACKUP_DIR/apollo-backup-$TIMESTAMP.tar.gz"

mkdir -p "$BACKUP_DIR"

# Backup all configs
tar czf "$BACKUP_FILE" \
    ~/.config/apollo-os/ \
    ~/.config/niri/ \
    ~/.config/sway/ \
    ~/.config/waybar/ \
    ~/.config/mako/ \
    ~/.config/rofi/ \
    ~/.config/swaylock/ \
    ~/.config/swayosd/ \
    2>/dev/null

echo "✅ Backup created: $BACKUP_FILE"

# Keep only last 5 backups
cd "$BACKUP_DIR"
ls -t apollo-backup-*.tar.gz | tail -n +6 | xargs -r rm

notify-send "Apollo OS" "Configuration backed up"
```

### 12. TTS Cache Cleanup
**Priorität:** Niedrig  
**Aufwand:** 15 Minuten  
**Impact:** Disk Space +100MB

**Neue Datei:** `scripts/apollo-os-cache-cleanup.sh`
```bash
#!/bin/bash
# Apollo OS - Cache Cleanup

TTS_CACHE="/tmp/apollo-tts-cache"

# Delete files older than 7 days
find "$TTS_CACHE" -type f -mtime +7 -delete 2>/dev/null

# Delete if cache > 100MB
cache_size=$(du -sm "$TTS_CACHE" 2>/dev/null | cut -f1)
if [[ $cache_size -gt 100 ]]; then
    # Delete oldest files
    find "$TTS_CACHE" -type f -printf '%T+ %p\n' | sort | head -n 20 | cut -d' ' -f2- | xargs rm
fi
```
